# Pad Vidéo

Sampler de pads pour vidéos YouTube : 16 pads qui sautent chacun à un timestamp de la vidéo,
une banque de drums synthétisés, un séquenceur et un sidechain réglable.

Page en ligne : voir l'onglet GitHub Pages du dépôt.

## Utilisation
- Pads vidéo : `1 2 3 4 / A Z E R / Q S D F / W X C V`
- Drums : `G H J K L M`
- Mode assign : une frappe de pad lui donne la position de lecture en cours.
- Tempo : tap tempo, détection depuis l'audio de l'onglet, ou depuis un fichier audio.
- Sidechain : profondeur, attack, release, trois courbes de release, source et cible au choix.

Les voix de drums sont synthétisées dans la page. Aucun sample tiers n'est distribué ici.
